# Миграция на рабочего бота

## Шаги для переноса на нового бота

### 1. Обновление токена в Render Dashboard

1. Войдите в [Render Dashboard](https://dashboard.render.com/)
2. Перейдите в ваш сервис `projectguard-backend`
3. Откройте раздел **Environment** (Переменные окружения)
4. Найдите переменную `BOT_TOKEN`
5. Обновите значение на новый токен: `8345160158:AAH56IAP4x4bhttVbaPrOZ-MJdCXjDSlMpY`
6. Сохраните изменения
7. Render автоматически перезапустит сервис

### 2. Обновление локального .env файла (для разработки)

Если у вас есть локальный файл `.env` в папке `backend/`, обновите там тоже:

```bash
# backend/.env
BOT_TOKEN=8345160158:AAH56IAP4x4bhttVbaPrOZ-MJdCXjDSlMpY
```

### 3. Настройка нового бота в Telegram

⚠️ **ВАЖНО:** После обновления токена нужно настроить нового бота:

1. **Установите Webhook для нового бота:**
   - Бот автоматически установит webhook при запуске
   - URL webhook: `https://projectguard-prod-7-1.onrender.com/api/telegram/webhook`

2. **Проверьте, что бот работает:**
   - Отправьте команду `/start` боту в Telegram
   - Бот должен ответить и показать кнопку для входа в систему

3. **Убедитесь, что бот может отправлять сообщения:**
   - Пользователи должны начать диалог с ботом (отправить `/start`)
   - Только после этого бот сможет отправлять им уведомления

### 4. Проверка после миграции

После обновления токена проверьте:

1. ✅ Логи в Render Dashboard - не должно быть ошибок о токене
2. ✅ Команда `/start` работает в Telegram
3. ✅ Уведомления отправляются (создайте тестовую защиту)
4. ✅ Webhook работает (проверьте логи на наличие ошибок webhook)

### 5. Что НЕ нужно делать

- ❌ Не нужно менять код
- ❌ Не нужно пересобирать приложение
- ❌ Не нужно менять базу данных
- ✅ Только обновить переменную окружения `BOT_TOKEN`

### 6. Если что-то пошло не так

Если после обновления токена бот не работает:

1. Проверьте логи в Render Dashboard
2. Убедитесь, что токен правильный (без лишних пробелов)
3. Проверьте, что webhook установлен правильно
4. Убедитесь, что новый бот не заблокирован в Telegram

### 7. Откат на старый бот (если нужно)

Если нужно вернуться на старый бот:
- Просто обновите `BOT_TOKEN` обратно на старый токен в Render Dashboard
- Сервис автоматически перезапустится
