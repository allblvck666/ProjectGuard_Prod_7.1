1. Подключи репозиторий GitHub

#### Frontend сервис (projectguard-frontend):

2. Выбери `render.yaml` как источник конфигурации
3. Проверь, что `VITE_API_URL` установлен автоматически из render.yaml

## ⚠️ Важные моменты для бесплатного тарифа

1. **Хранилище:** Используется ephemeral storage (`/tmp/data.sqlite3`) - данные могут теряться при перезапуске сервиса. Для production рекомендуется использовать внешнюю БД (PostgreSQL, MongoDB Atlas бесплатный тариф и т.д.)
2. **Sleep:** Бесплатные сервисы "засыпают" после 15 минут неактивности. Первый запрос может быть медленным (~30 сек)
3. **Лимиты:** 
   - 750 часов в месяц на сервис
   - 512MB RAM
   - Ephemeral storage (временное хранилище)

## 🔧 Если что-то не работает

1. **CORS ошибки:**
   - Проверь, что `FRONTEND_URL` на бэкенде совпадает с URL фронтенда
   - Проверь, что `VITE_API_URL` на фронтенде указывает на бэкенд

2. **Бесконечные перезагрузки:**
   - Открой консоль браузера, найди ошибки
   - Проверь, что токен сохраняется в localStorage
   - Проверь, что роль сохраняется правильно

3. **Админка не открывается:**
   - Проверь, что роль в localStorage = "superadmin" или "admin"
   - Проверь, что токен валидный (открой DevTools → Application → Local Storage)

4. **База данных не работает:**
   - Проверь, что `DB_PATH=/tmp/data.sqlite3` установлен
   - Проверь логи бэкенда на Render
   - Учти, что данные в `/tmp` могут теряться при перезапуске сервиса
