# Новый слой представления (редизайн)

Слой живёт рядом со старым: старые экраны не удалены и работают как раньше.
Новый экран включается флагом — по умолчанию везде старый.

## Флаги

| Флаг         | Что включает                          | Этап |
|--------------|---------------------------------------|------|
| `ui-list`    | список активных защит                 | 2    |
| `ui-detail`  | карточка защиты                       | 3    |
| `ui-create`  | создание + экран конфликта            | 4    |
| `ui-nav`     | нативные BackButton / MainButton      | 5    |
| `ui-admin`   | админка и статистика                  | 6    |
| `ui-kit`     | витрина дизайн-системы (`on` / `off`) | 1    |

Значения: `new` / `old` (для `ui-kit` — `on` / `off`).

Переключение:

```
?ui-list=new        включить новый список
?ui-list=old        вернуть старый
?ui=new             включить все новые экраны сразу
?ui-kit=1           открыть витрину дизайн-системы
```

Выбранное значение запоминается в `localStorage` (`pg_ui_flags`), поэтому переживает
перезапуск Mini App. Из консоли:

```js
window.__pgFlags()                     // текущее состояние
window.__pgFlags().set('ui-list','new')
window.__pgFlags().reset()             // вернуть всё к старому UI
```

## Файлы

- `tokens.css` — токены, обе темы, базовые компоненты (`pg-*`)
- `theme.js` — выбор темы из Telegram themeParams / colorScheme → `data-pg-theme` на `<html>`
- `flags.js` / `useFlags.js` — флаги и подписка на них
- `icons.jsx` — единый SVG-набор, `<Icon name="..." />` (эмодзи в новом слое не используются)
- `ui.jsx` — кнопка, карточка, бейдж, поле, сегмент, боттом-шит, состояния
- `UiKit.jsx` — витрина дизайн-системы (`?ui-kit=1`)

## Правила

- Бизнес-логика, `api.js` и контракты не меняются — только представление.
- Новые классы всегда с префиксом `pg-` (дизайн-система) или `pgl-` (экраны),
  чтобы не пересекаться со старым `styles.css`.
- Навигацию (шапка, «Назад», нижняя кнопка) рисует Telegram — своя не верстается.
