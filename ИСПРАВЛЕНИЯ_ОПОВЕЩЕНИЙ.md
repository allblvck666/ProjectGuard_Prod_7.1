# ✅ Исправления системы оповещений

## Дата: 2025-01-27

### 🎯 Проблемы, которые были исправлены

#### 1. **Оповещение за 2 дня до истечения защиты**
**Проблема:** Оповещения не приходили или приходили не вовремя.

**Исправление:**
- Увеличена частота проверки с 24 часов до 6 часов
- Теперь система проверяет истекающие защиты каждые 6 часов вместо раз в сутки
- Это обеспечивает более оперативные уведомления

**Файл:** `backend/main.py`, функция `check_expiring_protections()`
- Строка 3461: изменено `await asyncio.sleep(24 * 60 * 60)` на `await asyncio.sleep(6 * 60 * 60)`

---

#### 2. **Оповещения менеджеру при одобрении/отклонении защиты через админку**
**Проблема:** При одобрении или отклонении защиты через админку менеджер не получал уведомление.

**Исправление:**
- Добавлена отправка уведомлений менеджеру в функции `approve_pending()` (одобрение через админку)
- Добавлена отправка уведомлений менеджеру в функции `reject_pending()` (отклонение через админку)
- Уведомления отправляются асинхронно через `BackgroundTasks`

**Файл:** `backend/main.py`
- Функция `approve_pending()` (строка 136): добавлена логика отправки уведомления менеджеру
- Функция `reject_pending()` (строка 198): добавлена логика отправки уведомления менеджеру

**Формат уведомления при одобрении:**
```
✅ Защита одобрена

Защита: #ID
📦 SKU: ...
⏰ Дата истечения: ...
```

**Формат уведомления при отклонении:**
```
🚫 Защита отклонена

Защита: #ID
📦 SKU: ...
💬 Причина: ...
```

---

#### 3. **Оповещения менеджеру при отклонении через Telegram**
**Проблема:** При отклонении защиты через Telegram (кнопка "Отклонить") менеджер не получал уведомление.

**Исправление:**
- Добавлена отправка уведомления менеджеру в функции `reject_handler()` (отклонение через Telegram)
- Уведомление отправляется после обновления сообщений для админов

**Файл:** `backend/main.py`
- Функция `reject_handler()` (строка 3843): добавлена логика отправки уведомления менеджеру

---

#### 4. **Защита уходит из списка запросов после одобрения/отклонения**
**Проблема:** Нужно было убедиться, что защита уходит из списка запросов.

**Статус:** ✅ Работает автоматически
- Список запросов формируется по `status='pending'`
- При одобрении статус меняется на `'active'`
- При отклонении статус меняется на `'rejected'`
- После изменения статуса защита автоматически исчезает из списка запросов

**Файлы:**
- `approve_pending()`: `UPDATE protections SET status='active' ...`
- `reject_pending()`: `UPDATE protections SET status='rejected' ...`
- `approve_handler()`: `UPDATE protections SET status='active' ...`
- `reject_handler()`: `UPDATE protections SET status='rejected' ...`

---

#### 5. **Синхронизация между админами**
**Проблема:** Если один админ дал ответ, у других должно обновляться сообщение.

**Статус:** ✅ Уже работает
- При одобрении/отклонении через Telegram (`approve_handler`, `reject_handler`) сообщения обновляются у всех админов через `tg_notifications`
- При одобрении/отклонении через админку (`approve_pending`, `reject_pending`) сообщения также обновляются у всех админов

**Механизм:**
1. При создании защиты уведомление отправляется всем админам и сохраняется в `tg_notifications`
2. При одобрении/отклонении система находит все сообщения через `SELECT chat_id, message_id FROM tg_notifications WHERE protection_id=?`
3. Обновляет все найденные сообщения через `bot.edit_message_text()`

3. ✅ Добавлена отправка уведомлений менеджеру при отклонении через админку
4. ✅ Добавлена отправка уведомлений менеджеру при отклонении через Telegram

6. ✅ Подтверждено, что синхронизация между админами работает корректно

### 🔍 Как проверить:
1. **Оповещения за 2 дня:**
   - Создайте защиту, которая истечет через 2 дня
   - Подождите до 6 часов (или меньше, если защита уже близка к истечению)
   - Проверьте, что уведомление пришло менеджеру

2. **Оповещения при одобрении/отклонении:**
   - Создайте защиту на проверке
   - Одобрите или отклоните её через админку
   - Проверьте, что менеджер получил уведомление в Telegram

3. **Синхронизация между админами:**
   - Создайте защиту на проверке
   - Одобрите или отклоните её через Telegram (один админ)
   - Проверьте, что у других админов сообщение обновилось

4. **Уход из списка запросов:**
   - Создайте защиту на проверке
   - Одобрите или отклоните её
   - Проверьте, что она исчезла из списка запросов в админке
