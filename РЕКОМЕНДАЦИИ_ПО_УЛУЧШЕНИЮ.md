## ⚙️ Раздел "Настройки"

### Текущее состояние
Раздел находится в разработке и содержит только заглушку.

### Рекомендуемый функционал

#### 🔐 1. Профиль пользователя
- **Редактирование личных данных:**
  - Имя (full_name) — редактируемое
  - Телефон — редактируемый с валидацией
  - Email (если есть) — редактируемый
  - Должность/позиция (position) — редактируемая
  - Компания (company) — редактируемая
  - Город (city) — редактируемый
  - Аватар/фото профиля (опционально)

- **Безопасность:**
  - Смена пароля (если используется)
  - Двухфакторная аутентификация (2FA) через Telegram
  - История входов (последние 10 входов с IP, датой, устройством)
  - Активные сессии (с возможностью завершить)

#### 🔔 2. Уведомления
- **Настройки уведомлений:**
  - ✅ Получать уведомления о новых защитах (для админов)
  - ✅ Получать уведомления о запросах на продление (для админов)
  - ✅ Получать уведомления о истекающих защитах (за 2 дня)
  - ✅ Получать уведомления об одобрении/отклонении защит
  - ✅ Получать уведомления о продлении защит
  - ✅ Получать уведомления об удалении защит
  - ✅ Получать уведомления о похожих защитах
  - Настройка времени отправки уведомлений (например, только в рабочее время)
  - Выбор каналов уведомлений (Telegram, Email, Push в приложении)

- **Telegram интеграция:**
  - Показать текущий Telegram ID
  - Кнопка "Привязать Telegram" (открывает бота)
  - Кнопка "Отвязать Telegram"
  - Тестовая отправка уведомления

#### 🎨 3. Внешний вид
- **Тема оформления:**
  - Переключатель светлой/темной темы (уже есть, но можно улучшить)
  - Выбор цветовой схемы (синяя, зеленая, фиолетовая и т.д.)
  - Размер шрифта (маленький, средний, большой)
  - Компактный/расширенный режим отображения

#### 📊 4. Отображение данных
- **Настройки списков:**
  - Количество элементов на странице (10, 25, 50, 100)
  - Сортировка по умолчанию (дата создания, дата истечения, статус)
  - Поля для отображения в таблице защит (чекбоксы)
  - Автообновление данных (включить/выключить, интервал)

#### 🔍 5. Фильтры и поиск
- **Сохраненные фильтры:**
  - Сохранить текущие фильтры как "Избранное"
  - Список сохраненных фильтров с возможностью переименования/удаления
  - Быстрый доступ к сохраненным фильтрам

#### 📱 6. Мобильные настройки
- **Оптимизация для мобильных:**
  - Включить/выключить вибрацию при уведомлениях
  - Звук уведомлений (включить/выключить)
  - Автоматическое определение местоположения (для заполнения города/адреса)
  - Разрешения на доступ к камере (для сканирования QR-кодов, если будет)

#### 🌐 7. Язык и регион
- **Локализация:**
  - Выбор языка интерфейса (русский, английский)
  - Формат даты и времени (DD.MM.YYYY, YYYY-MM-DD и т.д.)
  - Часовой пояс (автоматическое определение или ручной выбор)
  - Формат чисел (разделитель тысяч, десятичный разделитель)

#### 📤 8. Экспорт данных
- **Экспорт:**
  - Экспорт моих защит в Excel/CSV
  - Экспорт статистики в PDF
  - Настройка формата экспорта (какие поля включать)
  - Расписание автоматического экспорта (ежедневно, еженедельно)

#### 🔗 9. Интеграции
- **Внешние сервисы:**
  - API ключи для интеграций (если будут)
  - Webhook URL для отправки событий
  - Интеграция с календарем (Google Calendar, iCal)

#### 📈 10. Статистика и аналитика
- **Личная статистика:**
  - Показать мою статистику (количество созданных защит, успешных, закрытых)
  - Графики активности (по дням, неделям, месяцам)
  - Сравнение с другими менеджерами (если разрешено)

#### ⚠️ 11. Предупреждения и напоминания
- **Настройка напоминаний:**
  - За сколько дней напоминать о истечении (по умолчанию 2, но можно изменить)
  - Напоминания о необходимости продления
  - Напоминания о незавершенных защитах

#### 🗑️ 12. Управление данными
- **Очистка:**
  - Экспорт всех моих данных
  - Удаление аккаунта (с подтверждением)
  - Очистка истории просмотров
  - Очистка кэша приложения

## 👑 Раздел "Администратор"

### Текущее состояние
Админка имеет вкладки: Dashboard, Users, Managers, Requests, Pending. Функционал базовый, но можно значительно расширить.

### Рекомендуемые улучшения

#### 📊 1. Улучшение Dashboard (Дашборд)

**Текущее:** Показывает базовую статистику с карточками.

**Рекомендации:**
- **Расширенная статистика:**
  - График защит по дням/неделям/месяцам (линейный график)
  - Круговая диаграмма по статусам защит
  - График активности пользователей
  - Топ-10 менеджеров по количеству защит
  - Топ-10 менеджеров по успешности (% успеха)
  - Средний срок жизни защиты
  - Количество продлений за период
  - Карта с распределением защит по городам (если есть геоданные)

- **Виджеты (настраиваемые):**
  - Возможность добавлять/удалять виджеты
  - Перетаскивание для изменения порядка
  - Размер виджетов (маленький, средний, большой)

- **Фильтры на дашборде:**
  - Выбор периода (сегодня, неделя, месяц, квартал, год, произвольный)
  - Фильтр по менеджерам
  - Фильтр по статусам
  - Экспорт дашборда в PDF/Excel

- **Алерты и уведомления:**
  - Критические события (защиты истекли без действий)
  - Запросы на продление, требующие внимания
  - Новые пользователи за период
  - Неактивные менеджеры (не создавали защит N дней)

#### 👥 2. Улучшение вкладки "Пользователи"

**Текущее:** Список пользователей с возможностью редактирования роли, блокировки, удаления.

**Рекомендации:**
- **Расширенная информация о пользователе:**
  - Полная история действий пользователя (таблица с фильтрами)
  - Статистика пользователя (количество созданных защит, успешных, закрытых)
  - График активности пользователя
  - Список всех защит пользователя (с возможностью перехода к защите)
  - История входов пользователя
  - Последняя активность

- **Массовые операции:**
  - Выбор нескольких пользователей (чекбоксы)
  - Массовое изменение роли
  - Массовая блокировка/разблокировка
  - Массовое удаление
  - Массовое назначение менеджера
  - Экспорт выбранных пользователей

- **Фильтры и поиск:**
  - Расширенный поиск (по email, телефону, имени, компании, городу)
  - Фильтр по дате регистрации
  - Фильтр по последней активности
  - Фильтр по количеству защит
  - Сохраненные фильтры

- **Группировка:**
  - Группировка по ролям
  - Группировка по статусу (активные/заблокированные)
  - Группировка по менеджерам
  - Группировка по компаниям

- **Дополнительные действия:**
  - Отправить сообщение пользователю (через Telegram)
  - Сбросить пароль (если используется)
  - Просмотр логов действий пользователя
  - Копирование данных пользователя
  - Создание отчета по пользователю

#### 👔 3. Улучшение вкладки "Менеджеры"

**Текущее:** Список менеджеров с статистикой, возможность редактирования, удаления, просмотра защит.

**Рекомендации:**
- **Расширенная статистика менеджера:**
  - Детальная статистика (графики, тренды)
  - Сравнение с другими менеджерами
  - Прогноз успешности
  - Средний срок жизни защит менеджера
  - Топ партнеров менеджера
  - Топ городов менеджера

- **Управление защитами менеджера:**
  - Расширенный список защит с фильтрами
  - Массовые операции над защитами (закрыть, удалить, продлить)
  - Экспорт защит менеджера
  - График защит менеджера по времени

- **Назначение и перераспределение:**
  - Массовое перераспределение защит между менеджерами
  - Автоматическое назначение защит (по правилам)
  - Шаблоны для быстрого создания защит менеджером

- **Коммуникация:**
  - Отправить сообщение менеджеру
  - История коммуникаций с менеджером
  - Напоминания для менеджера

#### ⏰ 4. Улучшение вкладки "Запросы на продление"

**Текущее:** Таблица запросов с возможностью продления, отклонения, удаления.

**Рекомендации:**
- **Расширенная информация:**
  - История запросов на продление для защиты
  - Причина предыдущих отказов (если были)
  - Статистика по запросам (сколько одобрено/отклонено)
  - Фильтр по статусу (все, новые, обработанные)

- **Массовые операции:**
  - Выбор нескольких запросов
  - Массовое одобрение (с указанием количества дней)
  - Массовое отклонение (с общим комментарием)
  - Массовое удаление

- **Автоматизация:**
  - Правила автоматического одобрения (например, если запрос от проверенного менеджера)
  - Шаблоны ответов для отклонения
  - Напоминания о необработанных запросах

- **Аналитика:**
  - График запросов по времени
  - Топ менеджеров по количеству запросов
  - Среднее время обработки запроса
  - Процент одобренных/отклоненных

#### 🔍 5. Улучшение вкладки "Проверка" (Pending)

**Текущее:** Список защит на проверке с возможностью одобрения/отклонения.

**Рекомендации:**
- **Расширенная информация:**
  - Детальная информация о похожей защите (если есть)
  - История проверок пользователя (сколько одобрено/отклонено)
  - Комментарии от других админов (если проверяют несколько)

- **Массовые операции:**
  - Выбор нескольких защит
  - Массовое одобрение
  - Массовое отклонение (с общим комментарием)

- **Фильтры:**
  - По дате создания
  - По менеджеру
  - По партнеру
  - По городу
  - По наличию похожих защит

- **Приоритизация:**
  - Сортировка по приоритету (старые сначала, с похожими защитами и т.д.)
  - Метки/теги для защиты
  - Назначение проверяющего админа
